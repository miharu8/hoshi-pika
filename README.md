# ほしピカ (Hoshi-Pika)
> **〜星のナビで、いつでも気分上々ノート〜**

**SAKURA WORKS / 星の案内人：千鈴龍穂（Senrei Ryusui）** がお届けする、
星の運行（月齢・月相）と心理学（ホ・オポノポノ的ゼロ化）を組み合わせたプライベート・セルフリフレクションWebアプリです。

## 🌟 主な特徴
- **月齢・月相リアルタイム計算**: SVGを用いた月影表示と、毎日の静かなコンパスガイド。
- **四相調和（ゼロ化プロセス）**: 感情や記憶のノイズを *受容 ➔ 許し ➔ ゼロ ➔ 感謝* のステップで昇華。
- **ソルフェジオ周波数（432Hz / 528Hz）**: Web Audio APIによるリアルタイム音波によるマインドフルネス。
- **プライバシー重視**: 入力データはすべてブラウザのLocalStorageに保存。外部サーバー非送信。

## 🚀 デプロイ・公開方法 (Vercel)
1. 本リポジトリを GitHub にプッシュします。
2. Vercel と連携し、リポジトリを選択して「Deploy」をクリックするだけで即座に公開されます。
